1. Необходимо установить докер и wsl, просмотреть что нет никакой ошибки при запуске.
2. В папке проекта выполнить две команды  `docker compose up -d` (для запуска контейнера) и (`docker ps`) для проверки работы контейнера
4. Открыть  Metabase: http://localhost:3000
5. Подключить  базу: Host=`db`, Port=`5432`, DB=`bigdata`, User=`postgres`, Password=`student`
6. Синхронизировать данные и после синхронизации можно создавать виджеты
